# Hot-oiler WB JSA review choices - November 1, 2026

Mike requested two distinct hot-oiler drafts, one partly participatory, and then requested loading both into WB JSA for testing.

- A uses eight conventional work-step/hazard/control sections.
- B uses six short read-and-discuss sections with show/tell prompts and participation confirmations. The existing app captures acknowledgements, not typed answers to every prompt.
- Both are marked REVIEW, use separate review task tags, and belong only to Hots Oiler LLC. They do not replace Liquid Gold content or select an operational default for Hots.
- No real JSA is signed or submitted by this setup. Site/unit safety review is still required before operational adoption.
- The two-page PDF concepts remain outside Git in the task artifact directory. These JSON files are the app-compatible wording.

Research: OSHA Oil and Gas eTool Special Services / Hot Oiling; OSHA Hot Work; OSHA H2S Safety; OSHA3763 pressure-line controls; Sinopec Canada 2022 contractor handbook section 7.8; UK HSE hydraulic injection injury bulletin. Sources are linked in both PDF concepts. No company-specific gas alarm thresholds or operating pressure/temperature values were copied into the templates.
