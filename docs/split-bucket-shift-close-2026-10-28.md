# Unfinished ticket work and split reservation cancellation

Source only; no backend deployment or APK build/installation. Current branch `release/dashboard-compact-identity-20261015`. WB T companion source `d0c5c0db` on `codex/wbt-enroute-20261014` / mirrored `codex/wbt-current-20261004`.

Private incident evidence confirmed a shift ended at7:05 PM America/Chicago while a WB T split remained en route until7:56 PM. The authoritative close transaction had no check for unfinished ticket work. It now reads only the canonical authenticated company/driver's open invoices and in-progress/paused dispatches before writing authority/logout/odometer. Started invoices block; terminal documents and never-started previews do not. Read failures block closure. Queued dispatches are not queried as blockers. This is the enforced shift-close path, not a claim to have verified legacy direct REST lifecycle writes. Suite companion adds an explanatory alert; no shift record was edited for this work.

Split rule clarified by Mike: cancel middle B/C/D/etc by releasing its unsent allocation into the same bucket; preserve completed deliveries and other destinations. The final live planned continuation requires delivery/diversion/transfer while water remains. Unknown bucket/next-stop state fails closed. Explicit zero carry plus zero allocation can cancel the last. Cancelling unloaded A, or diverting loaded A before future legs start, retains its existing family behavior.

`resolveDriverJobCancellation` now accepts `cancel_split` (the new client uses it so an older backend rejects instead of applying obsolete semantics). Both old and new cancellation callers get the live family guard. A middle-leg cancellation transaction preserves the entire pre-allocation `dispatchCarryBbls` as the next pending destination's `inheritedBbls`, stores a replay receipt, cancels only the current dispatch/invoice and preserves other statuses/destinations. Example:120 carried,40 reserved and not delivered =>120 available, not160. Submitted tickets, transfer and ownership/linkage guards remain. A consumed/advanced handoff is not returned again on replay. No ticket, pickup packet, WB M history, AFR or shift event is manufactured by cancellation.
